## 지원 조합
managed 는 Cloud SQL 로 postgres 16, mysql 8.0 을 쓴다 (Terraform 미작성 — 능력표 verified: false).
in-cluster 는 GKE 안 postgres 16, volume 은 Persistent Disk 위 SQLite 다.

## 고치는 법
Cloud SQL 이 아직 없으므로 첫 배포는 in-cluster postgres 16 이나 volume SQLite(replicas 1)가 현실적이다.
