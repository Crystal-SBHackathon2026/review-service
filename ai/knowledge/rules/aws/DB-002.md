## 지원 조합
managed 는 RDS 로 postgres 16, mysql 8.0 을 쓴다 (업무 DB oneaction-review-db 가 postgres 16).
in-cluster 는 EKS 안 postgres 16, volume 은 EBS 볼륨 위 SQLite, external 은 이미 있는 postgres·mysql 접속이다.

## 고치는 법
mysql 이 필요하면 placement 를 managed(RDS mysql 8.0)로, postgres 면 managed 또는 in-cluster 로 둔다.
RDS 는 Terraform 으로 만들어지므로 명세만 바꿔서는 생기지 않는다 — 인프라 반영이 필요하다는 점을 설명에 적는다.
