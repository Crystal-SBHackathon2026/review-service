## 지원 조합
managed 는 RDS 로 postgres 16, mysql 8.0 을 쓴다 (업무 DB oneaction-review-db 가 postgres 16). external 은 이미 있는 postgres·mysql 접속이다.
in-cluster(EKS 안 postgres)와 volume(볼륨 위 SQLite)은 지원하지 않는다 — 지금 EKS 에는 EBS CSI 드라이버가 없어 PVC 를 만들 수 없다(2026-10-08 실측).

## 고치는 법
postgres·mysql 은 placement 를 managed(RDS)로 둔다. SQLite 를 쓰던 앱은 managed postgres 로 옮기거나, 데이터를 남길 필요가 없으면 DB 를 빼는 것을 사람이 정한다.
RDS 는 Terraform 으로 만들어지고 앱마다 DB 를 만드는 수단(Crossplane)은 아직 없다 — 명세만 바꿔서는 DB 가 생기지 않으므로 인프라 반영이 필요하다는 점을 설명에 적는다.
