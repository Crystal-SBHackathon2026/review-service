## 고치는 법
public 을 false 로 바꾸고, Terraform 에서 aws_s3_bucket_public_access_block 의 네 항목(block_public_acls,
block_public_policy, ignore_public_acls, restrict_public_buckets)을 모두 true 로 둔다. 외부 공유는 presigned URL 이나 CloudFront OAC 로 한다.
