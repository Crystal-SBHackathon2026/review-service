title: 이미지 아키텍처가 대상 노드와 맞지 않다
---
## 왜 위험한가
arm64 전용 이미지를 amd64 노드에 올리면(또는 반대) 컨테이너가 exec format error 로 바로 죽고 CrashLoopBackOff 가 된다.
Apple Silicon 에서 docker build 한 이미지가 기본으로 arm64 단일 플랫폼이라 자주 생긴다.

## 판정 기준
image.platforms 와 대상 환경 노드 아키텍처(catalog/targets.yaml arch)의 교집합이 비어 있다.

## 고치는 법
자동 수정하지 않는다 — 명세의 platforms 만 바꾸면 거짓말이 된다. 이미지를 대상 아키텍처를 포함해 다시 빌드한다:
docker buildx build --platform linux/amd64,linux/arm64. Dockerfile 의 FROM --platform 고정도 함께 확인한다.
