rule_id: RUN-001
doc_type: rule
provider: any
title: readiness 경로가 없다
---
## 왜 위험한가
readiness 가 없으면 Kubernetes 는 프로세스가 뜨자마자 트래픽을 보낸다. DB 연결 전·초기화 중 요청이 실패하고,
Argo Rollouts 의 progressDeadlineAbort 는 새 버전이 준비됐는지를 readiness 로 판정하므로 깨진 릴리스를 자동으로 멈추지 못한다.

## 판정 기준
runtime.health.readiness 가 없다.

## 고치는 법
자동 수정하지 않는다 — 경로를 명세에 적기만 하면 앱에 없는 경로라 Pod 가 영원히 준비되지 않는다.
앱에 준비 확인 경로(예: /readyz, DB SELECT 1 까지 확인)를 만들고 runtime.health.readiness 에 선언한다.
liveness 는 외부 의존성 없이 프로세스 생존만 본다(/livez).
