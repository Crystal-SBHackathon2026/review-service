title: SQLite 파일이 영속 볼륨 밖에 있다
---
## 왜 위험한가
컨테이너의 쓰기 계층은 Pod 가 다시 만들어지면 버려진다. SQLite 파일이 영속 볼륨에 없으면 재배포·재시작·노드 이동 때
데이터가 조용히 사라진다. 배포 직후 기능 검사는 통과하므로 첫 재시작 전까지 문제가 드러나지 않는다.

## 판정 기준
database.engine 이 sqlite, requirements.persistence 가 true 인데 database.volume 이 없거나,
가리키는 storage.volumes 항목이 없거나 persistent 가 false 다.

## 고치는 법
자동 수정 가능. storage.volumes 에 persistent: true 볼륨을 추가하고 database.volume 으로 가리키며 placement 를 volume 으로 둔다.
앱이 DB 파일 경로를 환경변수(database.env_var)로 받아 그 볼륨의 mount_path 아래에 파일을 만들어야 한다.
