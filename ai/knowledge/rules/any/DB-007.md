title: 관리형 DB 자동 백업 꺼짐
---
## 왜 위험한가
backup_retention_days 가 0 이면 RDS·Cloud SQL 이 자동 백업과 시점 복구(PITR)를 하지 않는다.
잘못된 마이그레이션·실수로 지운 데이터·장애로 깨진 볼륨을 되돌릴 방법이 없고, 수동 스냅샷이 없다면 데이터는 그대로 사라진다.
자동 백업은 저장 용량만큼만 과금되고 앱 동작에는 영향이 없다.

## 판정 기준
database.placement 가 managed 이고 backup_retention_days 가 0 이다. aws·gcp 에만 적용한다.

## 고치는 법
자동 수정 가능. backup_retention_days 를 1 로 바꾼다 (Terraform 기본값). 더 길게 둘지는 복구 목표에 맞춰 사람이 정한다.
보관 기간을 줄이는 수정은 하지 않는다.
